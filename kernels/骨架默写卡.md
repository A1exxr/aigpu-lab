## #1 逐元素 kernel 骨架（grid-stride + 边界）

要求：写出 `__global__` 签名、`idx` 计算、grid-stride 循环、越界 return。
考点：`idx = blockIdx.x * blockDim.x + threadIdx.x`；stride = `blockDim.x * gridDim.x`。

## #2 行级 kernel 骨架（一 block 一行）

要求：`base = blockIdx.x * cols`；`tid` 沿行；把整行读进寄存器/共享内存。
考点：`cols` 必须当参数传，不能写死；`base` 加在每个下标上。

## #3 两级归约（warp shuffle + 共享内存）★

要求：
1. 寄存器累加循环
2. warp 内 `__shfl_down_sync(0xffffffff, v, offset)`，offset 从 16 到 1
3. `lane == 0` 写共享内存
4. **一次** `__syncthreads()`
5. warp 0 读共享内存再 shuffle，`lane == 0` 写结果

考点：屏障只在"跨 warp 交换"处需要一次；数组大小 = `blockDim.x/32`，不是 `blockDim.x`。

## #4 行内 max/sum 归约 + 广播（softmax 骨架）

要求：两次归约（max、sum）+ 共享内存广播 + `__syncthreads()` 位置。
考点：第一次归约前写 `local_max = -FLT_MAX`；广播后所有线程都要能读到同一个值。

## #5 共享内存 tiling 骨架（load → sync → compute → sync）

要求：`__shared__ As[TS][TS]`；两个循环搬 A、B 块；`__syncthreads()` 两处；K 维分块累加。
考点：`k0` 步进 = tile 大小；`As[r][c] = A[(by*TS+r)*K + k0+c]`。

## #6 寄存器分块骨架（每线程 4×4 累加器）

要求：`float acc[4][4]` 清零；两层 unroll 读 smem 得 4 个 a、4 个 b；16 次 FMA；写回 C。
考点：`idx = r*4 + kk` 的行宽分母是 **tile 宽**（32），不是 64。

## #7 wmma 骨架（Tensor Core）

要求：`fragment` 三种声明；`load_matrix_sync` 用指针 + `ldm`；`fill_fragment(0)`；`mma_sync`；`store_matrix_sync`。
考点：`ldm` 是"行宽"；累加器用 `float`；写回前需要 `__syncthreads()` 或按 warp 分片。

## #8 attention QK 骨架（warp-per-j）

要求：`warp_id = tid/32`、`lane = tid%32`；外层 `j = warp_id`、步进 `num_warps`；内层 `d = lane`、步进 32；5 轮 shuffle 归约；`lane == 0` 写。

考点：为什么这样读 K 是合并访存（同一 j 的 d 连续）。

## #9 online softmax（单遍）+ split-L 版本 ★

要求（单遍）：维护 `m`、`l`、`acc[D/32]`；每来一个 token：`m_new = max(m, s)`；`alpha = exp(m - m_new)`；`l = l*alpha + p`；`acc = acc*alpha + p*v`；结尾 `out = acc / l`。
要求（split-L）：`chunk = ceil(L/NSPLIT)`；空段 `m = -INF`；合并 `M = max(m_i)`；`d = Σ d_i·exp(m_i - M)`；`acc = Σ acc_i·exp(m_i - M)`；`out = acc/d`。

考点：一个 `alpha` 只能基于"新的全局 max"算；空段若 `m=0` 会污染合并。

## #10 PagedAttention 块映射

要求：`seq = bh / H`、`h = bh % H`；`phys = page_table[(seq*MAXB + off)*BS + i]`；`krow = k_cache + ((phys*BS + i)*H + h)*D`。
考点：三层索引里"哪一维是头、哪一维是页"——分母 H 不是 D，那个坑你踩过。

## #11 INT8 反量化（scale 折叠位置）

要求：`k_scale[token]` 乘在"点积之后"；`v_scale[token]` 折进 `p`；尾块也要 `p *= sv`。
考点：K 的 scale 对 d 是常数 → 提到 d 归约后；V 的 scale 对 d 也是常数但**对 t 不是** → 只能折进 `p_t`。

## #12 host 侧 launch 骨架

要求：`auto grid = dim3(...)`、`dim3 block(...)`；算 grid 的两种方式（扁平 `ceil(total/threads)`、按行 `rows`）；`TORCH_CHECK` 检查；返回 `torch::Tensor`。
考点：参数换了数字要跟着换（这类错你犯过 9 次）。
